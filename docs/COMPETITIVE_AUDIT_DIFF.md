## The standing note

Future audits of this kind should read the **tree**, not the inventory: three "missing" Phase-A features
(layouts, link groups, the shortcut registry) were fully built when the report was written, and one
("cross-view symbol sync doesn't work") describes behaviour the app has had since the terminal board
landed. The re-runnable reconciliation method already used for the menus
(`docs/MENU_RECONCILIATION.md`) is the right shape for the next pass.
