# ModFlow OrderFlow Analysis Suite — Competitive Reanalysis Report

**Prepared for:** Moddy (OrderFlow-Analysis-Pro repo)
**Date:** 19 September 2026
**Scope:** Quantower, Bookmap, NinjaTrader, MetaTrader 5, Sierra Chart — GUI/layout/features/market-norms vs ModFlow current build
**Method:** Primary vendor documentation + independent reviews + existing in-repo UX studies (docs/ux-study/) + static read of ModFlow source (docs/ux-study/modflow_inventory.md). All competitor claims carry a source URL; ModFlow counts are real grep/wc from the repo.

---

## 1. Executive summary

ModFlow is a genuinely broad analytical surface — 32 rail items, 29+ views, footprint/CDV/TPO/heatmap/depth/tape/alerts/replay all present — and it already integrates feed adapters for every competitor in this report (Quantower, NinjaTrader, Bookmap, MT5, Sierra Chart) as data sources. That is a real differentiator no other tool here offers.

Where ModFlow falls short of market norms is not in *analytics breadth* but in three areas: **(a) order-entry and execution identity** (every competitor here is also a trading terminal — ModFlow is read-only analytics), **(b) workspace/persistence depth** (ModFlow has one rail+content frame; competitors let you stack independent OS windows, binds, groups, chartbooks, or profiles), and **(c) interaction density** (hotkeys, mouse grammar on the chart/ladder, right-click order placement, OCO/bracket management are table stakes the market expects).

The single most actionable insight: the market does not expect ModFlow to replace a broker terminal. It expects ModFlow to be the *best analytics layer that sits beside* one. That reframes every gap below — you are not competing with Quantower's 60 broker connections; you are competing with Bookmap's heatmap clarity and ATAS-level footprint readability inside a window that also has ModFlow's broader context (news, calendar, fundamentals, journal, signals).

## 2. Competitor breakdown

### 2.1 Quantower

**What it is.** Windows desktop trading terminal, broker-agnostic (60+ connections claimed), order-flow/volume-analysis heavy. Runs portable — no registry/AppData writes, uninstall = delete folder. (Source: [quantower.com/charting-and-analytics-features](https://www.quantower.com/charting-and-analytics-features), [completeTradersEdge review](https://completetradersedge.com/quantower-review/))

**Pricing.** All-in-One monthly = 70 (currency applied client-side, no symbol on page). Tiers: Free / Crypto / Multi-Asset / All-in-One. Free edition: 2 indicators per chart, 1 overlay, 1 connection. 7-day full trial on registration. Paid features à la carte. (Source: [quantower.com/pricing](https://www.quantower.com/pricing))

**GUI / layout model.**
- **The unit is an OS window, not a cell.** Every panel is a standalone window that sticks to neighbours, collapses to the taskbar. (Source: [help.quantower.com — Single Panel](https://help.quantower.com/quantower/general-settings/standalone-panels))
- **Four nesting layers, all persisted as XML:** Workspace → Bind (rectangle-select several panels → resize as one unit, separators stick) → Group (nested tabs, drag header over another) → Panel. (Source: [help.quantower.com — Binds](https://help.quantower.com/quantower/general-settings/binds), [Group of panels](https://help.quantower.com/quantower/general-settings/group-of-panels))
- **Control Center** is a docked panel pinned to screen top; its Minimize collapses *every* panel on *every* screen to taskbar. (Source: [help.quantower.com — Main Toolbar](https://help.quantower.com/quantower/general-settings/main-toolbar))
- **Link by colour.** Pick a link colour in two panels → titles colour-match → symbol syncs. Separate crosshair-sync setting per chart. (Source: [help.quantower.com — Link panels](https://help.quantower.com/quantower/general-settings/link-panels))
- **Panel corner menu** carries: Link, Create Bind, Create Panel (sub-menu: Order Entry, Chart, DOM Trader, Market Depth, Time&Sales, DOM Surface, TPO Chart, Symbol Info — all on *current symbol*), Duplicate, Save as Template, Apply Template, Set as Default, Always on Top, Export Data, Screenshot, Help, Settings. (Source: [help.quantower.com — Single Panel](https://help.quantower.com/quantower/general-settings/standalone-panels))
- **Favourites:** star any Sidebar tile → favourite panels bar on toolbar; star a connection → favourite tile with status dot (grey=disconnected, yellow=connecting, green=active) and ping-ms text. (Source: [help.quantower.com — Main Toolbar](https://help.quantower.com/quantower/general-settings/main-toolbar))
- **Templates persist panel params + display** and can be applied to any panel; "Set as Default" seeds new panels. (Source: [help.quantower.com — Templates](https://help.quantower.com/quantower/general-settings/templates))
- **17 languages claimed**, user-editable colour-variable themes, Themes Editor. (Source: [help.quantower.com — Themes editor](https://help.quantower.com/quantower/miscellaneous-panels/themes-editor))

**Order flow features that matter.**
- **DOM Surface** — heatmap-style visualization of limit order activity over time, shows where large orders sit / get pulled / liquidity shifts. Called "one of the best tools available at this price point" by third-party review. (Source: [completeTradersEdge review](https://completetradersedge.com/quantower-review/))
- **DOM Trader** — full order book with one-click execution.
- **Volume Profile, Footprint charts, Time & Sales** — all professional-grade, included.
- **150+ technical indicators**, custom C# scripting (Quantower Algo, Visual Studio / VS Code integration). (Source: [help.quantower.com — Quantower Algo](https://help.quantower.com/quantower/quantower-algo/introduction))
- **60+ broker/data-feed connections** across futures, stocks, forex, crypto. Third-party review corroborates. (Source: [completeTradersEdge review](https://completetradersedge.com/quantower-review/))
- **Option chain, Greeks, option strategies** support. (Source: [quantower.com/charting-and-analytics-features](https://www.quantower.com/charting-and-analytics-features))
- **Spreads and synthetic symbols** via simultaneous connections. (Source: [quantower.com/charting-and-analytics-features](https://www.quantower.com/charting-and-analytics-features))
- **Drawing tools, indicators, volume analysis tools** on the order flow chart. (Source: [quantower.com/blog/order-flow-trading-in-quantower](https://www.quantower.com/blog/order-flow-trading-in-quantower))

**Strengths.** Unmatched broker neutrality at this price. DOM Surface + Volume Profile + Footprint in one platform. Modern, responsive UI (reviewers note chart movements feel smoother than NinjaTrader's). Workspace/customization depth is exceptional for retail. Free tier is genuinely useful. Outstanding customer support (repeatedly praised; support team offers remote-desktop sessions). (Source: [completeTradersEdge review](https://completetradersedge.com/quantower-review/))

**Weaknesses.** Windows only. Steep learning curve. Market data subscriptions cost extra (not included in licence). Doc lag: help centre release notes trail the product by months (help says v1.146.11, site says 1.147.3 as of 18 Sep 2026). (Source: [completeTradersEdge review](https://completetradersedge.com/quantower-review/), [help.quantower.com — Release Notes](https://help.quantower.com/quantower/updates/latest-version) vs [quantower.com/release-notes](https://www.quantower.com/release-notes))

**Relevant ModFlow gap.** ModFlow has no panel-persistence model at all beyond the single frame. Quantower's Bind/Group/Workspace/Template/Default cascade is the market norm for "I set up a screen once and reuse it." ModFlow's Settings → Order-flow (reference layout) is a start but is not a saved workspace system.

### 2.2 Bookmap

**What it is.** Java desktop app, GPU rendering (OpenGL for chart, optional Direct3D for UI), heatmap-first order-flow visualisation. Sells "the full market depth and live order flow in a single view." Data refreshed 40 times/sec (25 ms/frame). (Source: [bookmap.com/features](https://bookmap.com/features/), [KB Welcome](https://bookmap.com/knowledgebase/docs/KB-Welcome), [WallStreetZen review](https://www.wallstreetzen.com/blog/bookmap-review/))

**Pricing.** Four tiers: Digital (free), Digital+, Global, Global+. Monthly/yearly/lifetime. Digital+ $19/mo, Global $49/mo ($468 annual / $990 lifetime), Global+ $99/mo ($948 annual / $1990 lifetime, "Recommended"). Market data billed separately: BookmapData $34-79/mo, dxFeed futures $37/mo per exchange, Rithmic $40-101/mo, crypto free. 50%-off first month on BookmapData. Feature gating: max symbols viewable 1/3/10/20 across tiers; some indicators "Replay mode only" on lower tiers. (Source: [bookmap.com/pricing](https://bookmap.com/pricing/), [Bullish Bears review](https://bullishbears.com/bookmap-review/))

**GUI / layout model.**
- **One main window, instruments as tabs.** Tabs detach three ways: drag-and-drop, double-click tab, right-click → "Open in a new window." Only one tab per instrument. Tab nav when crowded: side arrows, drop-down list, mouse scroll, Ctrl+Tab / Ctrl+Shift+Tab. (Source: [KB Tabs](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-Tabs))
- **No dock manager documented** — model is "tabs + detached OS windows" (inferred design position).
- **Per-instrument chart anatomy:** heatmap + volume dots + volume bars + BBO lines + last-price line, all toggleable from "visible components menu." Heatmap colour scale in the toolbar. Timeline can move to right side. (Source: [KB Main Chart](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapMainChart))
- **Right-side columns rail** (per-price analysis): Current Order Book, Volume (CVP/SVP), Trades Counter (CTC/STC), Quotes Counter (CQC), +/- Quotes Delta, Time & Sales, Trading DOM, Custom Notes / Cloud Notes. Columns inserted/hidden by right-click, widened by left-click, dragged by header, **can be dragged to either side of the chart.** (Source: [KB Columns](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-Columns))
- **Below chart:** Indicator Panel (CVD, Advanced CVD, PNL, position, Liquidity Tracker, API indicators). **Right side:** Widget Panel (current-value snapshots). Each indicator's display location set in Widget Settings (panel/widget/both). (Source: [KB Indicator Panel](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapIndicatorPanel))
- **Trade Control Panel** left of main chart when enabled; **Trade Status Panel** above chart (position, avg price, pending orders, total volume, P/L, unrealised P/L). (Source: [KB Studies configuration](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapStudiesConfiguration), [KB Orders Management](https://bookmap.com/knowledgebase/docs/KB-Trading-Orders-Management))
- **Bottom-left:** Information Bar (same data as tooltip, always visible). **Bottom-right:** session cluster — record control, trading status (real vs simulated), data type (live/replayed), active connections, **Data Ingest Indicator** (histogram of ingest load; at 100% and stuck = pending updates, Bookmap delays recenters). (Source: [KB Information Bar](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapInformationBar))
- **Time & Sales detachable.** Replay Panel has pin icon (keep visible / auto-hide). (Source: [KB Columns](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-Columns), [KB Select A Run Mode](https://bookmap.com/knowledgebase/docs/KB-GettingStarted-SelectRunMode))
- **Saved layouts = Workspaces (.bmw):** store full app layout + config, heatmap settings, visible components, activated add-ons, opened instruments. New/Open/Save/Save As; .bmw launchable by double-click; feed/workspace files shareable by direct link. Launches with most recent workspace by default. (Source: [KB Export and Import of Bookmap files](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-ExportImportBookmapFiles), [KB Open The Main Window](https://bookmap.com/knowledgebase/docs/KB-GettingStarted-OpenMainWindow))
- **Cross-chart sync:** one chart acts as master; adjusting range on master updates linked charts; optimal when same size; subordinate chart view changes disrupt sync. Crosshair is explicitly multi-instrument. (Source: [KB Supporting Features](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapSupportingFeatures))
- **Multi-monitor:** supported in practice (detach + move) but poorly documented; bug history full of multi-monitor crashes/disappearances. Positively: "All interface elements, including icons, have been enhanced to appear sharper and more detailed, ensuring full support for high DPI monitors." (Source: [KB Release Notes](https://bookmap.com/knowledgebase/docs/KB-ReleaseNotes))

**Interaction model (the good stuff).**
- **Heatmap zoom:** buttons, mouse wheel over heatmap/price axis, left-click-hold drag on time/price axis, "Zoom by Drag" rubber-band with green guide lines, Ctrl+Z to zoom out. Cursor-anchored zoom (wheel keeps cursor location centred). (Source: [KB Supporting Features](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapSupportingFeatures))
- **Drag mode (time travel over the book):** hold D to drag, M toggles; arrow keys 1px, Shift+arrows 10px; how far back is entitlement-gated (1hr or 24hr). (Source: [KB Supporting Features](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapSupportingFeatures))
- **Vertical re-centring policies:** auto on Best Bid/Ask, Trades, or Last Price; "None" for manual; "Recenter in Drag Mode" checkbox; tunable tolerance (percentage or absolute). (Source: [KB Supporting Features](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapSupportingFeatures))
- **Anti-clutter:** BBO lines auto-hide when pixel separation drops below threshold with hysteresis (`Reappear Threshold = Hide Threshold × (1 + Factor)`). Vertical smoothing filter (Auto/Manual/None) for zoomed-out views. (Source: [KB Main Chart](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapMainChart), [KB Heatmap settings](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapSettings))
- **Precision readout:** Data tooltip (time, date, timezone, bid/ask, order amount/price, traded volume); Information Bar mirrors; Crosshair toggle with axis label projection; axis labels globally switchable. (Source: [KB Supporting Features](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapSupportingFeatures), [KB Information Bar](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapInformationBar))
- **Drawing tools:** figures/text, Single Figure Mode, show/hide all per instrument, style changes, clear all, right-click edit/delete, Shift to constrain 45°, per-drawing axis highlighting, extended rectangles. (Source: [KB Supporting Features](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapSupportingFeatures))
- **Events list (range → dense table):** drag a period → popup with timestamp, instrument, source (trade vs order placed/removed), side, price, size, filters for volumes only / nanoseconds / current instrument only. (Source: [KB Supporting Features](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapSupportingFeatures))
- **Hover-first numeric disclosure:** hover volume dot → transaction volume + VWAP for that transaction; hover time+price → pending order counts. (Source: [KB Studies configuration](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapStudiesConfiguration), [KB Information Bar](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapInformationBar))
- **Volume dots/bars sub-console:** clustering (Smart/By time/By volume/By price/By price+aggressor), drawing types (Gradient/Solid/Pie), 2D vs 3D, total-vs-delta, min accountable dot volume, dot size, transparency, "Apply to Bars"/"Inherit from Bars," per-bar width 1-15px, draggable red line to resize bar area. Candlesticks overlayable with three OHLC definitions, zoom-driven candle aggregation, right-click candle → shortcut menu to full settings. (Source: [KB Traded Volume Visualization](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapTradedVolumeVisualization), [KB Candlestick View](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapCandlestickView))

**Keyboard/hotkeys (documented global set).** Ctrl+S screenshot, Esc closes config dialogues, Space pause/resume in Replay, ./, playback speed, arrows shift chart 1px in drag mode (Shift+arrows 10px), M toggles drag mode, hold D to drag, right-click empty toolbar space to find main window, Ctrl+T instrument subscription, Ctrl+W unsubscribe, Ctrl+Tab switch instruments, Ctrl++/- font size. Configurable cancel-all shortcuts per order type. Add-on layer adds hotkey-bindable trading actions (VWAP buy/sell, move limits/stops ± ticks, move stop to breakeven). (Source: [KB Appendix I Keyboard Hotkeys](https://bookmap.com/knowledgebase/docs/KB-Appendices-AI-KeyboardHotkeys), [Execution Pro](https://bookmap.com/knowledgebase/docs/Addons-Execution-Pro))

**Order-entry UX.** Click semantics on chart: left-click at/below bid = buy limit; left-click above/on ask = buy market; right-click at/above ask = sell limit; right-click at/below bid = sell market; Shift+click = stop. Labels auto-appear when cursor right of current-time line. One-Click Trading OFF by default (arm via dropdown, lock icon opens when on). Confirmation popups per order type, selectively disableable. TCP: per-click size (auto-reset to 0 after send), durations per order type (Day/GTC/FOK/IOC), stop type MKT or LMT with offset, quick size modification (click to add, Shift+click to subtract), cancel-sell/buy/all/flatten buttons, auto-bracketing TP/SL in ticks, trailing stop in ticks. TCP user-rearrangeable (right-click → customise, drag-and-drop items). Order lifecycle visual language: beige dots/lines = buy entries, magenta = sell entries. Middle-click order label cancels; click total label at price cancels all at price; Ctrl+middle-click cancels all at price level. Bracket orders OCO after trigger; client-side bracket/trailing warnings about disconnect loss. Queue-position visualisation via one-click add-on (blue vertical lines on order book histogram, pessimistic FIFO assumption). Replay + simulator as practice loop (three run modes, replay slider, "Skip To Next Data Point," record/replay of orders too). (Source: [KB Orders Management](https://bookmap.com/knowledgebase/docs/KB-Trading-Orders-Management), [KB Trading Configuration Panel](https://bookmap.com/knowledgebase/docs/KB-Trading-Configuration-Panel), [KB Order Types](https://bookmap.com/knowledgebase/docs/KB-Trading-Order-Types), [KB Select A Run Mode](https://bookmap.com/knowledgebase/docs/KB-GettingStarted-SelectRunMode))

**Add-on ecosystem as UX.** ~three dozen first-party add-ons documented (CVD, AVWAP, Footprint, Market Profile, DOM Pro, Execution Pro, Multibrackets, Tradermap, Stops & Icebergs, Liquidity Marker, Market Pulse, Trading Journal/Statistics, Correlation Tracker, Cross BBO, Python API, …). In-app Add-ons Manager (introduced 7.4). Third-party add-ons are .jar drops from marketplace. Vendor keeps 73% of paid add-on sales, 88% of non-license services. **"Vibe Coding Bookmap Add-ons — Starter Guide"** teaches users to build add-ons with Claude Code / Codex / Copilot / Cursor. Some add-ons data-entitlement dependent (Stops & Icebergs Sub-Chart needs MBO from Rithmic; Execution Pro live mode only Rithmic/CQG). (Source: [KB Add-ons index](https://bookmap.com/knowledgebase/docs/KB-GettingStarted-AddonsManager), [KB Add-ons Manager](https://bookmap.com/knowledgebase/docs/KB-GettingStarted-AddonsManager), [KB Vibe Coding Starter Guide](https://bookmap.com/knowledgebase/docs/KB-Bookmap-Vibe-Coding-Starter-Guide), [KB Marketplace FAQ](https://bookmap.com/knowledgebase/docs/KB-Help-FAQs-Marketplace))

**Visual design.** Dark by default, colour-mapped liquidity (black→blue→yellow→orange→red, redder = more liquidity). Two legacy greyscale maps opt-in. Perceptual scaling: upper/lower cut-offs (percentile % or exact contract count), automatic contrast algorithm (scales to current book's max, adjustable frequency, re-adjusts on recentre), manual brightness/contrast sliders, Dimming, Large Size Highlight (greyscale-only), "Apply color scheme globally." Aggressor colouring is two-colour gradient (configurable), not fixed pair; stronger colour = more aggressive. Element-level colour theming with save/import profiles, per-element Restore color/Restore All. Density intentionally high — everything individually toggleable. Font: global font-size zoom (Ctrl++/-); DOM Pro add-on has Font Size, Row Size, Theme (dark/light). Accessibility: not documented as palette-driven — custom-colour-driven. Rendering fragility part of the contract: disable GPU when seeing distorted charts/freeses; toggle Direct3D/OpenGL-for-UI when parts render in wrong places. (Source: [KB Heatmap settings](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapSettings), [KB Main Chart](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapMainChart), [KB Traded Volume Visualization](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapTradedVolumeVisualization), [KB Colour Settings](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapColourSettings), [KB Performance Issues](https://bookmap.com/knowledgebase/docs/KB-Errors-Performance-issues))

**Onboarding.** Structured first-run: register/download → install adapter → connect → subscribe → open main window. Three run modes. Launchpad some users never see (Digital Free users may not see it — no Trading/Replay mode). (Source: [KB Select A Run Mode](https://bookmap.com/knowledgebase/docs/KB-GettingStarted-SelectRunMode), [KB Getting Started index](https://bookmap.com/knowledgebase/docs/KB-GettingStarted-SubscribeToInstruments))

**Strengths.** Best-in-class heatmap visualisation — the category-defining product. Liquidity heatmap + order book + time & sales in one integrated view. 40Hz refresh. Replay mode (tier-gated) is a killer practice feature. Add-on ecosystem with user-build path (Vibe Coding guide). Colour-scale/perceptual-knob depth is unmatched.

**Weaknesses.** Java desktop — memory-heavy (~8GiB free RAM recommended for Bookmap alone, "heavy use" 32GB). Expensive at top tier ($99/mo + separate data). Multi-monitor fragile per bug history. Linux support "limited." No mobile app. Doc navigation is icon-mediated and not uniform — KB repeatedly explains where a setting lives because it moves between releases. (Source: [KB System Requirements](https://bookmap.com/knowledgebase/docs/KB-IntroductionToBookmap-SystemRequirements), [bookmap.com/pricing](https://bookmap.com/pricing/), [KB Release Notes](https://bookmap.com/knowledgebase/docs/KB-ReleaseNotes), [WallStreetZen review](https://www.wallstreetzen.com/blog/bookmap-review/))

**Relevant ModFlow gap.** ModFlow's heatmap view (Liquidity map, Level events, Fresh walls) is the direct competitor to Bookmap's spine. ModFlow cannot match Bookmap's 40Hz heatmap rendering or its drag-mode time-travel. But ModFlow can match and exceed Bookmap's *contextual integration* — Bookmap has no news, calendar, fundamentals, journal, or multi-venue signals. ModFlow's edge is "heatmap + everything else."

### 2.3 NinjaTrader 8

**What it is.** Windows desktop trading platform (WPF/XAML), Free tier with real-time data + simulated trading, Order Flow+ suite (footprint, cumulative delta, volume profile, market depth), SuperDOM, Chart Trader, ATM strategies, large 3rd-party ecosystem. License keys removed in 8.1.1 (Mar 2023); account-plans-and-power-ups model. (Source: [ninjatrader.com/pricing](https://ninjatrader.com/pricing/), [NT8 help — 8.1.1](https://ninjatrader.com/support/helpguides/nt8/8_1_1.htm))

**Pricing.** Free ($0/mo, $0.39 micro / $1.29 standard per side), Monthly $99/mo ($0.29 / $0.99), Lifetime $1,499 one-time ($0.09 / $0.59). All plans include Desktop+Web+Mobile, top-of-book data, free simulated trading. **Order Flow+, Market Replay, Pulse and other advanced tools unlocked by funding a live account.** Kinetick end-of-day data built in; real-time "as low as $60/month." (Source: [ninjatrader.com/pricing](https://ninjatrader.com/pricing/))

**GUI / layout model.**
- **Control Center is the shell + taskbar.** One default window always on screen; four verb menus (New / Tools / Workspaces / Connections) + eleven content tabs (Orders, Strategies, Executions, Positions, Accounts, Log, Messages, Connection Status). (Source: [NT8 help — Control Center](https://ninjatrader.com/support/helpguides/nt8/control_center.htm))
- **Every surface is an independent OS window:** Chart, SuperDOM (Static/Dynamic), Level II, Market Analyzer, Market Watch, Time & Sales, News, Order Ticket, Basic Entry, FX Pro, FX Board, Options Chain, Alerts Log, Strategy Analyzer, Account Data, Trade Performance, Pulse, NinjaScript Editor/Output, Strategy Builder, Calendar (8.1.7). (Source: [NT8 help — New Menu](https://ninjatrader.com/support/helpguides/nt8/new_menu.htm))
- **Workspaces = saved window arrangements, one visible at a time.** Multiple can be open but only one active (filled green rectangle). SHIFT+F3 toggles. At shutdown, prompted to save. At least one must remain open or temp one created. Multi-monitor users report needing all 15 windows in ONE workspace because two workspaces can never display simultaneously. (Source: [NT8 help — Workspaces Menu](https://ninjatrader.com/support/helpguides/nt8/workspaces_menu.htm), [NT blog](https://www.ninjatrader.com/futures/blogs/intro-to-ninjatrader-desktop-control-center/), [Discourse "Multi screen problem"](https://discourse.ninjatrader.com/t/multi-screen-problem/5674))
- **Workspace lifecycle:** create/save/save-as/open/close/remove(confirmed, irreversible)/import/export. Prior versions recoverable via Tools → Database Management → Restore Workspace; 10 versions retained by default, configurable ("Versions of recovery workspaces"). Global prefs: "Reopen all previously open workspaces at startup," "Global Drawing Objects Across Workspaces," "Global link button across workspaces." (Source: [NT8 help — Workspaces Menu](https://ninjatrader.com/support/helpguides/nt8/workspaces_menu.htm), [NT8 help — Options General](https://ninjatrader.com/support/helpguides/nt8/general_section.htm))
- **Tabs:** various windows tabbed; add with +, remove via ✕ (never last tab), drag to reorder, right-click tab → Close Tab / Rename / Close Other Tabs / Duplicate In New Tab / Duplicate In New Window / Move To New Window. Ctrl+Tab switches. Tab titles accept tokens: @INSTRUMENT, @INSTRUMENT_FULL, @PERIOD, @ACCOUNT, @FUNCTION, @ATM, @DATASERIES and _ALL variants. Type `++MSFT` into Time & Sales overlay selector → new tab pre-loaded. (Source: [NT8 help — Using Tabs](https://ninjatrader.com/support/helpguides/nt8/using_tabs.htm))
- **Tabs carry text, not identity** — no platform way to colour a tab; third-party indicator exists explicitly because "NinjaTrader 8 has no way to color chart tabs." (Source: [Discourse "Maverick — color your chart tabs"](https://discourse.ninjatrader.com/t/maverick-color-your-chart-tabs-indicator/7204))
- **Docking: none documented.** Window arrangement delegated to Windows snapping; users report needing PowerToys or NVIDIA utilities to tile evenly. Per-window Always on top (SuperDOM Properties → Window). 8.1.7 fix: "First maximize extended beyond the visible monitor area." (Source: [NT8 help — Properties SuperDOM](https://ninjatrader.com/support/helpguides/nt8/properties_superdom.htm), [NT8 help — 8.1.7](https://ninjatrader.com/support/helpguides/nt8/8_1_7.htm), [Discourse "Multi screen problem"](https://discourse.ninjatrader.com/t/multi-screen-problem/5674))

**Navigation & IA.**
- **Menus are the IA.** New menu = flat catalogue of ~20 window constructors. Tools menu = platform-configuration drawer (Instruments, Instrument Lists, Database Management, Hot Keys, Historical Data, Commissions, Risk, Trading Hours, Vendor Licensing, Import/Export, Remove NinjaScript Assembly, Global Simulation Mode, Client Dashboard, Settings). (Source: [NT8 help — New Menu](https://ninjatrader.com/support/helpguides/nt8/new_menu.htm), [NT8 help — Tools Menu](https://ninjatrader.com/support/helpguides/nt8/tools_menu.htm))
- **Two-level settings split:** global in Control Center (Tools → Settings); per-surface in right-click Properties dialog inside the window. **What it is.** Native Windows desktop client (single EXE + DLLs, OpenGL rendering), deliberately dense professional trading client, futures/stocks/forex/options. Company in business since 1996. Detached charts can be "always on top" + all detached charts minimised/restored together. (Source: [SC docs — Order entry](https://www.sierrachart.com/))

(Source: [SC Support Board](https://www.sierrachart.com/), [SC Support Board — Thread 93271](https://www.sierrachart.com/SupportBoard.php?ThreadID=93271))

**Relevant ModFlow gap.** Sierra Chart's "everything is a study" + study collections + user-editable menus/shortcuts is the most sophisticated configurability model in this report. ModFlow's settings panels are a start; SC's study-collection + per-study inputs/subgraphs split + user-editable right-click menus is the market-norm ceiling for "I build my own analysis setup and save it."

## 5. Market norms consumers and experienced users expect

These are the things the market assumes a paid order-flow/analytics tool provides. ModFlow already meets many; the gaps are where it stands out as "not yet."

### 5.1 Identity & positioning norms
- **A tool in this category is expected to be a trading terminal OR a clear analytics layer that explicitly sits beside one.** ModFlow is the latter, which is fine — but it must make that identity explicit so users don't expect order entry and feel misled. Bookmap and ATAS-style tools own the "analytics + optional execution" space; ModFlow should too.
- **"Market data is billed separately" is a universally understood norm.** Every competitor in this report says it. ModFlow's current data-feed story (Alpaca free feed, plus the adapters) should be surfaced as clearly as Bookmap's data-pricing table.
- **Free tier or free trial is expected.** ModFlow is free (this build), which is a strength. The market also expects a demo/replay mode with data — ModFlow has Replay.
- **Cross-platform is increasingly expected but not universal.** MT5 is the exception that proves the rule (Win/macOS/Linux/web/mobile). ModFlow's Windows-only + WebView2 is acceptable for a v1 analytics tool; the market norm is "at least Windows, ideally macOS too."

### 5.2 Layout & persistence norms
- **Saved layouts that survive restart are table stakes.** ModFlow does not have this. Every competitor does (workspaces, .bmw, chartbooks, profiles).
- **Multi-panel / multi-window with some grouping is expected.** ModFlow's single-rail single-frame model is unusual — most users expect at least tabs or detachable sub-windows.
- **Templates/profiles that travel between symbols or views are expected.** ModFlow's Settings → Order-flow reference layout is a seed of this but not a full system.
- **"I set up my screen once and reuse it" is the core workflow expectation.** ModFlow cannot do this today.

### 5.3 Interaction norms
- **Keyboard hotkeys for common actions are expected.** ModFlow has 1-9 rail accelerators but no comprehensive system.
- **Mouse grammar on the chart/ladder is expected IF the tool does order entry.** ModFlow doesn't do order entry, so this is a "when you add terminal mode" norm, not a today norm.
- **Right-click context menus that surface the actions you need are expected.** ModFlow has rail + menu bar; SC's user-editable right-click menus are the ceiling.
- **Undo for destructive actions is expected where possible.** ModFlow doesn't appear to have trade-action undo (it has no trade actions).
- **Cross-view symbol sync (change symbol in one view → others follow) is expected in multi-view tools.** ModFlow does not have this.

### 5.4 Analytics norms
- **Footprint + CVD + volume profile + DOM/depth + heatmap is the analytical minimum the market expects from an order-flow tool.** ModFlow has all of these — this is a strength.
- **Replay / market replay for practice is expected.** ModFlow has Replay.
- **Alerts (visual + audio + push) are expected.** ModFlow has Telegram alerts + alert sounds.
- **Scanner / radar / watchlist for finding setups is expected.** ModFlow has Scanner (rail), Trackers (8 cards), Radar, Watchlist.
- **"I can build my own analysis setup and save it" is increasingly expected.** SC Study Collections, Bookmap workspaces, NinjaTrader templates, MT5 templates+profiles. ModFlow does not have this.

### 5.5 Visual norms
- **Dark theme default is expected in this niche.** ModFlow has dark/light/contrast/density/accents themes — good.
- **Perceptual scaling on heatmaps (colour scale, contrast, dimming) is expected if the tool has a heatmap.** ModFlow's heatmap settings exist but are shallower than Bookmap's.
- **"I can see what symbol/context I'm in at a glance" is expected.** ModFlow has topbar pills (engine, ws, source, live) + symbol picker — good, but no link-colour title sync.

## 6. Improvement suggestions for ModFlow

These are ranked by **market impact per implementation effort**, assuming the goal is "best analytics layer that sits beside a broker terminal" rather than "replace a broker terminal."

### 6.1 High-impact, moderate-effort (do next)

**1. Saved workspaces / layouts (ModFlow's single biggest gap vs every competitor).**
- **What to build:** A workspace system that saves: active view, rail scroll position, which cards/KPIs are visible per view, panel sizes if you add resizable panels, symbol + timeframe per view, settings presets. Persist as JSON in the existing storage system (storage.py / config_store.py). Add "Save layout," "Load layout," "Export/Import layout file," and a dropdown of saved layouts on the Settings → Order-flow reference layout page (or a new Workspaces section).
- **Market norm this matches:** Quantower Workspaces (XML), Bookmap .bmw, NinjaTrader workspaces, SC chartbooks, MT5 profiles.
- **Why:** This is the #1 thing a power user asks: "I set up my screen once and reuse it." ModFlow has 31 views — without saved layouts, each session is manual setup.

**2. Cross-view symbol sync (link by symbol).**
- **What to build:** A link-colour system: each view that has a symbol picker gets a link colour selector (drop a small colour dot in the view head or topbar). Views with the same link colour share symbol. A "Link All" option sets all to one colour. Colour appears as a dot/badge on the rail item or view head (like Quantower's coloured panel titles). Crosshair sync is a second pass (only relevant for chart + heatmap views).
- **Market norm this matches:** Quantower link by colour, NinjaTrader link buttons, Bookmap master-chart sync, MT5 chart switch bar.
- **Why:** With 31 views, a user watching one symbol across footprint + CVD + depth + tape + heatmap expects them to move together. Today each view is manually set.

**3. Comprehensive hotkey system.**
- **What to build:** Extend keys.js from digit→rail to a full system: a Hot Keys settings panel (like NinjaTrader's Tools → Hot Keys) where each action (switch view, toggle rail, start/stop engine, open replay, screenshot, toggle a view's pause, etc.) is bound to a key combo; conflict detection; a "print/export hotkey sheet" button (like NinjaTrader's printable list); global vs view-scoped bindings. Keep the 1-9 rail accelerators but document the shift caveat (setup wizard insertion).
- **Market norm this matches:** NinjaTrader Hot Keys window (category/global/order-entry, conflict detection, printable), SC global customizable shortcuts + trading shortcuts gated, Bookmap 20+ global documented + configurable cancel-all per order type, MT5 assignable hotkeys + user outranking predefined.
- **Why:** Power users in this niche are keyboard-driven. ModFlow's current 1-9 is a hint of the capability, not the capability.

**4. Study-collection / analysis-layout reuse.**
- **What to build:** A "Save current analysis setup as a collection" feature: snapshot which views are open, which cards/KPIs visible, which pattern thresholds are set, which tracker filters are active, the symbol + timeframe. Apply a collection to another symbol or restore a previous session. This is complementary to workspaces (workspace = screen layout; collection = analysis config).
- **Market norm this matches:** SC Study Collections, Bookmap workspace config, NinjaTrader templates, MT5 templates+profiles.
- **Why:** A user who builds a careful footprint+CVD+profile setup for one symbol wants to replay it on the next symbol without re-clicking 12 settings.

### 6.2 High-impact, higher-effort (plan for terminal mode)

**5. Order-entry identity + minimal terminal mode.**
- **What to build (when ready):** A "Terminal" mode (there is already a Classic|Terminal mode switch in the topbar — #modeSwitch, index.html:125-130) that adds: a ladder/DOM panel (reuse the depth order-book data but lay it out as a ladder with price rows + bid/ask columns + click-to-trade grammar), a Chart Trader-style inline order panel on the chart (collapsed view option: keep order+position display, hide the rest), bracket/OCO management, position + P&L display. This is the biggest feature set and should be scoped separately. ModFlow's existing feed adapters (NT bridge, MT5 feed, Bookmap client, DTC client) give it the data plumbing to connect to a broker for execution — that is a real advantage over a greenfield build.
- **Market norm this matches:** NinjaTrader Chart Trader + SuperDOM + ATM, Bookmap TCP + brackets + one-click, SC Trade DOM + right-click entry, Quantower DOM Trader + Order Entry, MT5 one-click + dialogs.
- **Why:** This is the only way ModFlow becomes a true competitor to the execution side of these tools. Until then, ModFlow's identity should be "analytics layer" and the terminal mode should be an explicit opt-in upgrade, not a confused half-state.

**6. Replay with order recording.**
- **What to build:** Extend the Replay view (source/transport/simulated account already exist) to record and replay orders (placing, modifying, cancelling) alongside data — like Bookmap's replay that records orders too. This turns Replay into a practice loop, not just a data replay.
- **Market norm this matches:** Bookmap replay (records orders, 3 run modes, simulator), NinjaTrader Market Replay (requires live account funding).
- **Why:** A practice loop is a retention + training feature the market expects.

### 6.3 Polish / visual depth (do alongside)

**7. Heatmap perceptual-scaling depth.**
- **What to build:** Extend the heatmap settings (atlas.js/atlas-v2.js heatmap config) with Bookmap-grade knobs: upper/lower cut-offs as percentile % or exact count, automatic contrast algorithm with adjustable re-adjust frequency (and re-adjust on recentre), dimming, large-size highlight, "apply colour scheme globally" across all heatmap views. This is purely additive to the existing heatmap — no new views.
- **Market norm this matches:** Bookmap heatmap settings (percentile cut-offs, auto contrast, dimming, large-size highlight, apply globally).
- **Why:** ModFlow's heatmap is its direct Bookmap competitor; matching Bookmap's perceptual depth on the heatmap specifically is the highest-ROI visual improvement.

**8. Per-view pause control (close the gap F6).**
- **What to build:** The inventory flags 20 views with no pause control (heatmap, cvd, profile, frames, strategy, performance, replay, alerts, instruments, platforms, journal, calendar, settings, logs, watchlist, news, fundamentals, options, studies, alpaca). Add a consistent pause/resume affordance to each live data view. The topbar already has #btnStart/#btnStop/#btnRestart — extend a per-view pause chip where meaningful.
- **Why:** Power users pause to read a snapshot without the numbers changing. It's a small feature with high perceived quality.

**9. View-head link-colour badge + symbol-in-this-view indicator.**
- **What to build:** When a view has a symbol, show it in the view head (like "ES 09-26" or the symbol's short name). When a view is linked by colour, show the link colour dot. This answers "what am I looking at and is it synced?" without a dialog — the same quiet UX work MT5's status bar does with template+profile name.
- **Market norm this matches:** MT5 status bar (active template + profile always visible), Quantower link-colour title, NinjaTrader link buttons.

**10. Onboarding / discoverability pass.**
- **What to build:** A first-run guide that is not just the Setup wizard. Surface: what ModFlow is (analytics layer, not a broker terminal — be explicit), what each major view does (one line each for the 31 views), how to save/load a layout (once built), how to link views by symbol (once built), where hotkeys are configured (once built). The existing Guide view (guide.js) is a start — extend it into a proper onboarding surface. Add a "What ModFlow is and isn't" block in Settings or the Guide, modeled on Bookmap's structured first-run + Quantower's Sidebar panel launcher grouped by function.
- **Why:** MT5 is the cautionary tale — a free, ubiquitous tool whose users call it unintuitive. ModFlow has 31 views; without onboarding, most users will only use 3-4 of them.

### 6.4 What NOT to build (deliberate choices)

- **Do not chase broker count.** Quantower's 60+ connections is a multi-year bet. ModFlow's advantage is depth per symbol, not breadth of brokers.
- **Do not build a dock manager like Quantower's OS-window model yet.** ModFlow's single-frame model is simpler and fine for an analytics layer. Add tabs/detach as part of workspace persistence, not as a full docking system.
- **Do not add order entry without a clear terminal-mode boundary.** Half an order-entry system (a ladder but no brackets, a chart order panel but no OCO) is worse than none — it invites users to expect execution ModFlow doesn't safely provide. When terminal mode comes, build it as a complete, gated mode.
- **Do not copy Sierra Chart's menu-as-API model without the docs.** SC works because its public support board + numbered docs compensate for the density. ModFlow would need equivalent support infrastructure to copy that model, and it doesn't have it yet. Copy SC's study-collection idea, not its menu-customisation-as-IA.
