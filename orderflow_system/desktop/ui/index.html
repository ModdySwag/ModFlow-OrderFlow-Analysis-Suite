Alpaca
a US brokerage account as an optional data source — stocks, ETFs, options, crypto, news and the market calendar
Symbols
which symbols this account will serve

Ticker format is Alpaca's: equities and ETFs as plain symbols (AAPL), crypto as a pair (BTC/USD). The free plan streams 30 symbols; history is readable for any symbol the account can reach.
Live feed
idle
loading…
The feed starts with the engine: set Data source to Alpaca (or All) in Settings, then press Start engine. Depth views stay on the exchange feed — Alpaca publishes no order book.
What Alpaca adds — and what it cannot
AddsUS equities / ETFs / options / crypto instruments, real-time IEX tape (30 symbols on the free plan), 15-minute-delayed full-market history, Benzinga news, the US market calendar, and — in the next phase — paper orders, positions and a portfolio view.
Cannot addOrder-book depth. Alpaca publishes trades, quotes and bars only, so the heatmap, the DOM ladder and the participants'-intent reader stay on the exchange feed, which does publish depth.
Data honestyFree-plan real-time US data is IEX (a single venue, a small share of volume); full-market SIP data is readable once it is older than 15 minutes. The app labels which feed a panel is showing.
Everything else the program can change at runtime lives in Settings.
